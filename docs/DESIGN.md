# ARGOS 디자인 시스템: Technical Folio

기준일 2026-10-09. 이 문서는 `docs/src/` 모든 조각이 따르는 시각 규약입니다. 2026-10-09 전체 평가(`review/DESIGN_REVIEW.md`)의 결론을 규칙으로 옮겼습니다.

## 1. 콘셉트

**로봇 제조사의 기술 도면집(technical folio).** 공장 도장색인 그래파이트 위에 신호 황색 하나를 씁니다. 백과사전처럼 정밀한 판면을 짭니다.

- 장식이 아니라 **도면 규약**이 고급스러움을 만듭니다. 쓰는 장치는 표제란, 지시선, 번호 풍선, 같은 축척, 헤어라인 괘선, 표입니다.
- 한 화면에는 **결론 하나**만 둡니다. 같은 숫자는 페이지 전체에서 한 번만 크게 말하고, 다른 곳에서는 참조로 처리합니다.
- 회의실 프로젝터 기준으로 판단합니다. 투사하면 검정이 흰색의 5% 수준으로 떠오르므로, 면의 명암 차이가 아니라 **선(괘선)으로 구획**합니다.

## 2. 금지 목록 (AI 템플릿 문법)

다음 요소는 쓰지 않습니다.

- **배경과 질감:** 순수 검정(#0x0x0x) 배경, 필름 그레인, 방사형 스포트라이트 비네트(히어로 3D 스튜디오 조명은 예외).
- **제목과 텍스트:** 영문 대문자 + 넓은 자간 오버라인(`01 · ANATOMY` 류), font-weight 200·300, 그라디언트 텍스트, 은색·금색 금속 질감 제목.
- **면과 카드:** 18px 이상 둥근 모서리 카드 그리드, 반투명 유리 카드, backdrop-filter 블러, 금색 그라디언트 막대, 글로우, box-shadow 발광.
- **장식 인터랙션:** 커스텀 커서, 모서리 브래킷 HUD, 가짜 텔레메트리(AZ/EL 좌표), "SCROLL TO …" 라벨.
- **번호 중복:** "FINDING n / 9" 같은 번호 장치. 한 블록에는 번호를 하나만 붙입니다.

## 4. 타이포그래피

| 역할 | 서체 | 규칙 |
|---|---|---|
| 제목, 큰 수치, 연도 (`--f-display`) | Pretendard | 섹션 제목은 700, clamp(34px, 4.2vw, 60px), letter-spacing -0.03em. 큰 수치는 600~700에 tabular-nums |
| 본문 (`--f-body`) | Pretendard | 본문 17px/1.75, 보조 16px. 400~600 |
| 도면 표기 (`--f-mono`) | Pretendard | 같은 서체로 씁니다. 13px 이상, 500, tabular-nums, letter-spacing 0~0.04em. 대문자 변환은 금지합니다 |

모든 서체는 Pretendard 하나입니다(jsDelivr `pretendardvariable-dynamic-subset`). 위계는 서체를 바꾸지 않고 굵기, 크기, 색, 괘선으로 만듭니다. 표기 라벨은 고정폭이 아니므로 숫자 정렬에는 `font-variant-numeric:tabular-nums`를 씁니다.

**프로젝터 하한.** 1440px 화면을 3m 스크린에 띄우는 것을 기준으로 합니다.
- 화면에 보이는 모든 글자는 **13px 이상**입니다. SVG는 viewBox 축소를 감안한 실제 렌더 크기로 잽니다.
- 차트 축과 범례는 13px 이상, 차트 수치는 14px 이상입니다.
- 읽어야 하는 문장은 `--muted` 이상으로 씁니다.

한글 제목에는 `word-break:keep-all`과 `text-wrap:balance`를 적용합니다. 줄표 대신 쉼표, 마침표, 괄호를 씁니다. 문체는 "~입니다/~합니다"로 통일합니다.

## 5. 섹션 머리: 표제란 (sheet head)

섹션마다 **한 번만** 셸 유틸 `.sheet`를 씁니다. 이것이 페이지의 유일한 번호 체계입니다.

```html
<div class="sheet">
  <span class="sheet-no">ARG-02</span>
  <span class="sheet-name">해부도</span>
  <span class="sheet-meta">구성요소 12</span>
</div>
<h2 class="h-display">…</h2>
<p class="lead">…</p>
```

생김새는 전체 폭 헤어라인 위에 놓인 한 줄 표제란입니다. 도면번호, 섹션명, 이 섹션의 규모 한 가지를 담습니다.

## 6. 레이아웃과 리듬

- 12열 그리드를 씁니다. `.wrap` 최대 1360px, 거터는 `--gutter`입니다.
- 섹션 배경은 bg와 bg-2를 번갈아 씁니다(02 bg, 03 bg-2, 04 bg, 05 bg-2, 06 bg, 07 bg-2).
- 섹션 시작 방식은 섹션마다 다르게 둡니다. 도면 한 장, 비교표, 영상, 큰 수치 하나, 연표, 사전 조판 순서입니다. 모든 섹션이 "제목, 리드, 카드 그리드" 공식을 반복하지 않게 합니다.
- 스크롤 pin은 히어로 한 곳에만 둡니다. 다른 섹션은 pin하지 않습니다.

## 8. 검증

- `python3 build.py --check`가 통과해야 합니다.
- 1440x900과 375x812에서 콘솔 에러 0, 가로 스크롤 0이어야 합니다.
- 13px 미만 글자는 0개여야 합니다(`document.querySelectorAll('*')`의 computed font-size로 잽니다).
- 같은 5명(RED, SILVER 독창성, SILVER 프로젝터, BLUE, GOLD)이 다시 채점하며, 합격선은 평균 9.5입니다.
