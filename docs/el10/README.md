# 휴머노이드 로봇 백과사전

초등학교 3학년이 혼자 읽을 수 있는 카툰 렌더링 로봇 백과사전이다. 분류는 Prototype(7점 실험)이다.

## 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 완성본. 일러스트 18장이 인라인된 단일 파일. 이것만 공유하면 된다 |
| `content.json` | 본문 정본(로봇 10종, 몸 구조 7, 역사, 직업 5, 퀴즈 8, 낱말 10, 약속 4) |
| `images/*.svg` | 카툰 렌더링 일러스트(굵은 잉크 선, 셀 셰이딩 1단 그림자, 하이라이트) |
| `assets/style.css`, `assets/app.js` | 코믹북 UI와 인터랙션(플립 카드, 퀴즈·색종이, 읽어 주기, 10초 도전) |
| `build.py` | 위 파일을 합쳐 `index.html`을 만든다 |

## 수정 방법

1. 글은 `content.json`, 그림은 `images/<id>.svg`, 디자인은 `assets/`를 고친다.
2. `python3 build.py`를 실행한다.

## 갱신 기준

- 사실(연도, 제조사, 키)은 공개 자료로 확인된 것만 쓴다. 불확실하면 "약"을 붙이거나 뺀다.
- 문장은 25자 안팎, "~요" 톤, 어려운 말은 괄호로 풀어 쓴다.
- SVG id는 파일 id를 접두어로 붙인다(인라인 충돌 방지).

## 제작 방식

casting 스킬 로스터로 팀을 짰다. #6 리서치·#28 교정(본문), #23 이미지 생성 ×4(일러스트 병렬), 조립·QA는 오케스트레이터가 직접 했다.
