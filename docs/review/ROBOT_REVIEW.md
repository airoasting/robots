# TITAN 히어로 로봇 평가 (2026-10-08)

목적: 히어로 로봇을 10점으로 끌어올리기 위한 기준 문서입니다. 평가 대상은 `review/01~04` 캡처입니다(옵티머스 형태와 샌드 팔레트, 복부 확장 적용 후 상태).
갱신 기준: 개선 단계를 하나 마칠 때마다 같은 각도로 다시 캡처하고, 같은 다섯 명에게 다시 채점받아 이 표를 고칩니다.

| 영화 로봇 콘셉트 아티스트 (ILM·Weta) | 실루엣, 캐릭터성, 디테일 리듬 | 6.0 |

공통 진단: 색과 UI는 8점대이지만, 로봇 본체는 "관절 핀을 꽂은 목각 데생 인형"으로 읽힙니다.

## 합의된 결함 (지적한 평가자 수 순)

1. 골반이 속옷처럼 보임 (5/5). 갈색 직물 삼각형이 원인입니다.
2. 팔다리가 원형 단면 회전체라 마네킹 다리처럼 보임, 굵기와 테이퍼의 위계도 없음 (4/5)
3. 사람 근육 조각(대흉근 볼륨, 가운데 골)이 마네킹 인상을 강화함 (3/5)
4. 관절이 좌우 대칭 흑백 도넛이라 장난감 핀으로 보임 (4/5)
5. 목이 가늘고 길며 머리가 작고, 위를 쳐다봄. 완성 순간에 얼굴 라이트도 안 보임 (4/5)
6. 외피가 석고나 나무처럼 평평함. 하이라이트, 이음선, 모따기가 없고 면이 각져 보임 (3/5)
7. 무릎을 편 차렷 자세, 약한 림 라이트와 접지, 로봇이 화면의 40%만 차지함 (4/5)
8. 선형 액추에이터가 아무것도 구동하지 않고, 골격이 직물로 보임 (엔지니어)

## 10점 로드맵

### 1단계 (난이도 하, 7.5점 목표)
- 골반을 샌드 하드 셸로 바꾸고 다리 절개를 깊게, 허리에 얇은 새틴 밴드
- 가슴 근육 조각을 제거하고 넓은 평면과 측면 모따기로
- 외피 재질: roughness 0.42, clearcoat 0.7, env 1.0, 때 얼룩 1/4, 정점 병합과 각진 노멀(toCreasedNormals), 분할 2배
- 자세: 무릎 약 15도 굽힘, 머리 수평, 미세한 체중 이동
- 목을 짧고 굵은 칼라 셸로, 머리 10% 확대
- 시그니처: 얼굴 라이트 라인이 완성 시 확실히 점등, 흉골 수직 라이트 심 1줄
- 커스텀 스튜디오 환경광(소프트박스 스트립), 키를 카메라 반대편으로, 후방 림 2개
- 카메라: 로봇이 화면 높이의 65~80%, 망원 FOV

### 2단계 (난이도 중, 9점 목표)
- 회전체를 슈퍼타원 로프트(D자 단면)로 교체하고 비례표 재설정(허벅지 0.088→무릎 0.056, 정강이 0.064→발목 0.036)
- 무릎과 팔꿈치 캡, 비대칭 관절 모듈(모터 몸통, 출력 플랜지, 볼트 원, 중공축)
- 어깨를 요크와 삼각근 캡으로, 몸통에서 자라난 형태로
- 셸마다 파팅 라인 2~3개(2mm 틈)
- 접촉 그림자, GTAO, 약한 블룸(배경을 씬 안으로 옮긴 뒤)

### 3단계 (난이도 상, 10점 목표)
- 선형 액추에이터를 크랭크에 연결해 아이들 중 실제로 신축
- 조립 5박자(골격 → 액추에이터 펌프 → 배선 → 셸 클램셸 → 센서 점등)
- 100% 와우 모먼트: 조명 0.4초 어둡게, 얼굴 라인 중앙에서 좌우로 점등, 이음선을 따라 빛이 흐름, 고개를 들어 관람자를 봄
- 호버: 대상 부품 프레넬 아웃라인, 나머지 60% 감광

## 하지 말 것 (평가자 합의)
- 약한 1차 형태를 판, 볼트, 발광, 파티클로 덮지 않습니다. 이미 거절된 방향입니다.
- 사람 해부학(복근, 대흉근, 엉덩이)을 더 정교하게 조각하지 않습니다.
- 승인된 색을 톤매핑이나 노출로 건드리지 않습니다.
- 투명 캔버스 위에 후처리를 바로 얹지 않습니다(알파가 깨짐).
